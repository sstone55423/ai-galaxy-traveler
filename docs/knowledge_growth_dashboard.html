Interpretation

The standard K-research probe accumulates observational and operational knowledge throughout the transit — refined navigation data, pre-arrival system characterization, improved bootstrap plans. The range-maximizer arrives faster but starts its knowledge clock at zero. For distant targets, the transit K-gain in standard mode can rival the arrival burst itself.

Model scope

This is a first-order model to fix orders of magnitude and design direction. K is a dimensionless index. Loss parameters (archive half-life, context drift rate) are illustrative; their real values are unknown. The gain rate post-arrival is set at 5x cruise gain as a placeholder for high-data-rate in-situ observation. See the knowledge-growth paper for the full K(t) = G(t) - L(t) framework.
