Candidate mechanisms (click)

The brittle failure (immutable core)A wrong value, unfixed — but bounded and visible against the preserved baseline. Chosen knowingly.
The corrupting failure (amendable core)A value-governing procedure breached — invisibly, with unbounded reach into the machinery that governs every value.

The six requirements

Click a mechanism. Green chips: aspects of process it secures. Red: where it falls short.
The antinomy: every mechanism secures some aspect of process — agreement, latency tolerance, auditability, standing. None secures the correctness of a terminal-value change, because relative to the values undergoing change there is no standard available to the probe by which the change can be judged correct. The conservative default — an immutable core, its brittleness priced honestly — is chosen because the horns are not symmetric: prefer the failure that is bounded and visible.
