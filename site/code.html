Code tools

The repository includes zero-dependency Python modules for the star catalogue, propulsion, energy, routing, and the deep-time wanderer simulation.

Local star and routing engine

Use `code/galaxy_sim.py` to measure distances, find neighbours, and compute routes between the 127 real stars within 100 light-years.

Open galaxy_sim.py

Propulsion models

`code/propulsion.py` compares laser sail, fusion, and nuclear-electric cruise options for flyby scenarios and reachable range.

Open propulsion.py

Power and redundancy

`code/energy.py` models source sizing, decay, converter redundancy, and long-duration mission reliability.

Open energy.py

Self-replicating wanderer

`code/wanderer.py` simulates a slow patient fleet that crawls between stars, replicates, and grows a lineage over millennia.

Open wanderer.py
