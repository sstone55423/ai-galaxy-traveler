### Payload paper — Section 3, A Mind That Improves Without Drifting

**SAGE: A Statistical Acceptance Gate for Self-Evolving Agents** — Wang, Y., Xia, L., Liu, R., Zhang, Z., Wu, H., Yang, Y., He, J., Guo, Y., & Lei, K. (2026), arXiv:2609.36043
[link](https://doi.org/10.48550/arXiv.2609.36043) · verified via arXiv API (title, 2026-09-28, all nine authors)

Bears on: the claim that the mutable cognitive layer is safe under almost unlimited self-modification because it adopts changes "only when it can establish that they serve its objectives," in the spirit of a system that rewrites its own code once it has proven the rewrite beneficial (Schmidhuber 2007). The paper asserts the proof requirement and never says what the proof is.

> What the proof-before-adoption requirement must consist of is not a formality, and the obvious implementation of it fails. Wang et al. (2026) show that the acceptance rule actually used by self-evolving agents — keep any edit that raises an aggregate validation score — admits permanent regressions, because an edit can lift the average while breaking items the system already handled, and is biased upward besides by the Optimizer's Curse, since the best score observed on a finite noisy validation set overstates an edit's true value; their remedy is per-item paired comparison on identical validation items, plus a one-sided test that commits an edit only when its wins are statistically reliable and abstains otherwise. The setting is benchmark skill documents rather than a megayear cognitive layer, but for a probe with no external evaluator the asymmetry is the whole point: a regression accepted once is inherited by every descendant, so the gate must be conservative by construction rather than merely favorable in expectation.

Reference added: Wang, Y., Xia, L., Liu, R., Zhang, Z., Wu, H., Yang, Y., He, J., Guo, Y., & Lei, K. (2026). SAGE: A statistical acceptance gate for self-evolving agents. *arXiv preprint* arXiv:2609.36043.

Confidence: high. Both mechanisms — regression under aggregate scoring, and the Optimizer's Curse bias — are stated in the abstract. The prose claims no megayear result and should not be strengthened to one.

### DNA mission-ledger paper — Section 9, What the Architecture Secures, and What It Does Not

**Tracekit: Tamper-Evident Intent-Reasoning-Action Auditing for Autonomous Coding Agents** — Ghosh, B. (2026), arXiv:2609.35659
[link](https://doi.org/10.48550/arXiv.2609.35659) · verified via arXiv API (title, 2026-09-28, single author Bravish Ghosh confirmed)

Bears on: the sentence following the Nagaraj (2026) model-hiding discussion — "Tamper-evidence proves the recorded history is intact; it does not prove the history is complete." The section frames incompleteness as what a probe withholds at write time. It does not name the other half: a chain is blind to loss at its own newest end, which is exactly what physical decay produces.

> The gap is not only about what is withheld at write time; a hash chain is also blind to loss at its own end. Tracekit, an empirical hash-chained audit ledger for self-logging autonomous agents, detects every edit, deletion, reordering, forged insertion and torn write across 1,600 random mutations, but tail truncation and wholesale re-chaining are caught only by external anchors, with detection falling to 0.47 at an anchoring interval of 300 records (Ghosh 2026). For this architecture that is a physical failure mode as much as an adversarial one, since strand loss at the chain's most recent end is exactly what decay produces: the probe's only anchors are its periodic refresh commitments and the checkpoints exchanged when contact resumes, so the interval between them — not the chain itself — sets how much recent history can disappear without evidence.

Reference added: Ghosh, B. (2026). Tracekit: Tamper-evident intent-reasoning-action auditing for autonomous coding agents. *arXiv preprint* arXiv:2609.35659.

Confidence: high. The 1,600-mutation sweep, the tail-truncation and re-chaining exceptions, and the 0.47 detection figure at 300-record anchoring intervals are all stated in the abstract. The deep-time reading is marked as the series' own inference.

**Learning to Cover Locally: Graph Neural Combinatorial Optimization under a Hard Information Horizon** — Loevenich, J. F., Moehlenhof, T., Holz, L., Schwarzer, M., Huerten, T., & Lopes, R. R. F. (2026), arXiv:2610.00422

Bears on: "This strategy does not require central coordination … No back-channel is required; each node applies the same rule to the same information." The section asserts that decentralized dispatch is sufficient; this supplies the condition under which that holds and the cost of violating it.
